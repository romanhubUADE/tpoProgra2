# SimpleLinkedQueue<E>

## Archivo fuente
- `src/queueModule/SimpleLinkedQueue.java`

## Tipo
Implementación dinámica de [[SimpleQueue]] usando nodos enlazados.

## Estructura interna
- `LinkedNode<E> first` (frente)
- `LinkedNode<E> last` (final)
- `int size`

## Ideas clave
- `enqueue` agrega al final.
- `dequeue` remueve del frente.
